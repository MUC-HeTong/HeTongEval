# HeTongEval | 和同开放评测与动态监测平台

**HeTongEval：面向低资源多语种与多模态基础模型的开放评测与动态监测平台**

**和而不同，智联万语。**

> 项目状态：规划与仓库结构建设阶段。评测代码、基准数据、模型适配器和排行榜尚未发布。

## 项目定位

HeTongEval 是 HeTong（和同）开源模型生态中的开放评测平台，计划提供统一评测、能力诊断、动态监测与可复现的评测报告。

## 规划中的评测方向

| 模块 | 方向 |
| --- | --- |
| HeTongEval-Text | 文本大模型评测 |
| HeTongEval-VL | 视觉语言模型评测 |
| HeTongEval-Audio | 语音与音频模型评测 |
| HeTongEval-Agent | 智能体能力评测 |
| HeTongEval-Safety | 安全与可信能力评测 |
| HeTongEval-Culture | 文化理解与价值对齐评测 |

## 评测生态

- **HeTongBench**：多语种多模态评测基准体系（规划中）
- **HeTongRank**：模型能力排行榜（规划中）
- **HeTongReport**：模型评测报告与能力诊断（规划中）

重点关注藏文、蒙古文、维吾尔文及其他低资源语言；实际支持的语言、任务及指标将以未来正式发布的版本为准。
