# HeTongEval

### 和同开放评测与动态监测平台

**HeTongEval: An Open Evaluation and Monitoring Platform for Multilingual and Multimodal Foundation Models**

**HeTongEval：面向低资源多语种与多模态基础模型的开放评测与动态监测平台**

**和而不同，智联万语。**

## Overview | 项目简介

HeTongEval is an open evaluation initiative focusing on multilingual and multimodal foundation models, with an emphasis on low-resource languages, comprehensive capability assessment, and continuous model monitoring.

HeTongEval（和同评测）旨在构建面向低资源多语种与多模态基础模型的开放评测体系，支持模型能力评估、动态监测、能力诊断和排行榜建设。

## Evaluation Directions | 评测方向

| Module | Description |
|---|---|
| HeTongEval-Text | 文本大模型评测 |
| HeTongEval-VL | 视觉语言模型评测 |
| HeTongEval-Audio | 语音与音频模型评测 |
| HeTongEval-Agent | 智能体能力评测 |
| HeTongEval-Safety | 安全与可信能力评测 |
| HeTongEval-Culture | 文化理解与价值对齐评测 |

## Evaluation Ecosystem | 评测生态

- **[HeTongBench](https://github.com/MUC-HeTong/HeTongBench)** — 多语种多模态评测基准体系（规划中）
- **[HeTongRank](https://github.com/MUC-HeTong/HeTongRank)** — 模型能力排行榜（规划中）
- **HeTongReport** — 模型评测报告与能力诊断（规划中）

## Low-Resource Language Evaluation

We aim to support evaluation for Tibetan, Mongolian, Uyghur, and other low-resource languages.

重点关注藏文、蒙古文、维吾尔文及其他低资源语言的模型能力评测。
