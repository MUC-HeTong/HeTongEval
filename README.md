# HeTongEval

**HeTongEval: An Open Evaluation and Monitoring Platform for Multilingual and Multimodal Foundation Models**

---

## Overview

HeTongEval is an open evaluation initiative focusing on multilingual and multimodal foundation models, with an emphasis on low-resource languages, comprehensive capability assessment, and continuous model monitoring.

## Evaluation Directions

| Module | Description |
|---|---|
| HeTongEval-Text | Evaluation of large language models |
| HeTongEval-VL | Evaluation of vision-language models |
| HeTongEval-Audio | Evaluation of speech and audio models |
| HeTongEval-Agent | Evaluation of agent capabilities |
| HeTongEval-Safety | Evaluation of safety and trustworthiness |
| HeTongEval-Culture | Evaluation of cultural understanding and value alignment |

## Evaluation Ecosystem

- **[HeTongBench](https://github.com/MUC-HeTong/HeTongBench)** — Multilingual and multimodal benchmark suite (planned)
- **[HeTongRank](https://github.com/MUC-HeTong/HeTongRank)** — Model capability leaderboards (planned)
- **HeTongReport** — Model evaluation reports and capability diagnostics (planned)

## Low-Resource Language Evaluation

We aim to support evaluation for Tibetan, Mongolian, Uyghur, and other low-resource languages.

## Project Status

**Status: Under Development**

The evaluation framework, benchmark resources, and technical documentation will be released progressively.
